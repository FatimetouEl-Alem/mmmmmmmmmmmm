# Fonction_publique

Site du Ministère de la Fonction Publique et du Travail — version bilingue (français / arabe).

- Pages en français : `index.html`, `actualites.html`, `publications.html`, … (15 pages)
- Pages en arabe : mêmes noms précédés de `ar-` : `ar-index.html`, `ar-actualites.html`, … (15 pages)
- Le bouton « عربية / FR » en haut de chaque page ouvre la même page dans l'autre langue.
- Tous les fichiers sont à la racine (pas de sous-dossier) : `style.css`, `main.js`, images.

Déploiement Netlify : `netlify.toml` publie la racine, aucune commande de build.
